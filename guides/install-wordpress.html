Install WordPress in one click

cPanel's installer sets up WordPress, its database, and your admin login in one go. You'll be writing your first post a couple of minutes from now.

Before you start

You can install before your domain points at Dredge, but you won't be able to see the site until it does. If you haven't connected it yet, start with Connect a domain.

Install it

  1. In cPanel, open WordPress Manager (or Softaculous Apps Installer and choose WordPress) and click Install.
  2. Choose Protocol: pick https://.
  3. Choose Domain: pick your domain or subdomain.
  4. In Directory: leave this empty so the site is at the top of the domain, not at yourdomain.com/wp.
  5. Site Name and Site Description: anything; you can change them later.
  6. Admin Username: pick something other than admin, which is the first name attackers try. Use a long password and an email address you check.
  7. Click Install and wait for the confirmation.

Log in

Go to https://yourdomain.com/wp-admin and sign in with the admin username and password you just chose. WordPress Manager in cPanel also has a one-click login button.

First things to do

  • Settings → General: set your time zone and check both addresses start with https://.
  • Settings → Permalinks: choose Post name for clean links like /about-us/.
  • Delete the sample post, page, and any themes and plugins you won't use. Fewer plugins means fewer things to update and fewer ways in.
  • Keep WordPress, themes, and plugins updated. WordPress Manager can turn on automatic updates.

Moving an existing WordPress site instead of starting fresh? Follow Move a WordPress site to Dredge.
