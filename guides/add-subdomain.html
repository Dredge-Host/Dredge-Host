Domains · 3 min read

Add a subdomain like blog.yourdomain.com

A subdomain is an address in front of your main domain, like blog.yourdomain.com or shop.yourdomain.com. Each one can hold a completely separate site.

Before you start

Your main domain needs to point at Dredge already (see Connect a domain). Because Dredge runs your DNS, any subdomain you create here works straight away; there's nothing to change at your registrar.

Create the subdomain

  1. In cPanel, open Domains and click Create A New Domain.
  2. Type the full subdomain, for example blog.yourdomain.com.
  3. Untick Share document root. cPanel suggests a folder such as blog.yourdomain.com; that's where this subdomain's files will live.
  4. Click Submit.

Put something on it

  • A WordPress site: follow Install WordPress and choose the subdomain from the domain list.
  • Your own files: follow Upload a website and upload into the subdomain's folder instead of public_html.

HTTPS

AutoSSL picks up new subdomains on its next run, usually within a few hours. To speed it up, open SSL/TLS Status in cPanel and click Run AutoSSL.

Removing a subdomain later, from Domains, doesn't delete its folder. Delete the folder in File Manager too if you no longer need the files.
