Your site · 4 min read

Turn on HTTPS everywhere

Every domain on Dredge gets a free certificate automatically. This guide makes sure every visitor actually uses it.

Step 1: Check your certificate

In cPanel, open SSL/TLS Status. Each domain should show a green padlock. If one doesn't:

  • Make sure the domain points at Dredge (see Connect a domain). Certificates can only be issued for domains that point here.
  • Click Run AutoSSL and give it a few minutes.
  • Still red? The row explains why. Email us the message and we'll sort it out.

Certificates renew on their own. You never need to buy or install one.

Step 2: Redirect everyone to HTTPS

  1. In cPanel, open Domains.
  2. Switch on Force HTTPS Redirect next to each domain.

Now anyone who types http://yourdomain.com lands on https://yourdomain.com.

Step 3: For WordPress sites

  1. Go to Settings → General and make sure both WordPress Address and Site Address start with https://.
  2. If some pages show a padlock with a warning, they have “mixed content”: images or scripts still loading over http://. Install Better Search Replace and replace http://yourdomain.com with https://yourdomain.com across all tables.

Hard-coded links in themes or custom code aren't covered by the search-and-replace. Your browser's developer tools (Console tab) list any file still loading over http://.
