Change your PHP version

Some plugins, themes, or frameworks need a specific PHP version. You can switch in about thirty seconds.

Switch the version

  1. In cPanel, open MultiPHP Manager.
  2. Tick the checkbox next to the domain you want to change.
  3. Pick a version from the PHP Version dropdown on the right.
  4. Click Apply.

The change takes effect immediately. Refresh your site to confirm it's working.

Check which version you're running

The MultiPHP Manager page shows the current version next to each domain. You can also create a file called info.php in your site's root with this content:

<?php phpinfo();

Visit yourdomain.com/info.php in a browser. Delete the file when you're done — it exposes server details you don't want public.

Change PHP settings

If you need to adjust values like upload_max_filesize, max_execution_time, or memory_limit:

  1. Open MultiPHP INI Editor in cPanel.
  2. Select your domain from the dropdown.
  3. Change the values you need and click Apply.

Which version to pick

As a rule of thumb, use the newest version your site supports. WordPress currently recommends PHP 8.1 or newer. If you're unsure, try the latest version — if something breaks, you can switch back in the same way.
