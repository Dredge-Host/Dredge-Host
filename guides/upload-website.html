Your site · 5 min read

Upload a website with File Manager or FTP

If your site is a folder of files, such as HTML, CSS, and images, uploading it is all it takes to put it live.

Where your files go

Your main domain serves whatever is inside the public_html folder. Extra domains and subdomains each have their own folder, which you chose when you added them. The page visitors see first must be called index.html (or index.php) and sit directly inside that folder.

Option 1: File Manager (easiest)

  1. On your computer, compress your site folder into a .zip file.
  2. In cPanel, open File Manager and double-click public_html.
  3. Click Upload, choose your .zip, and wait for it to finish.
  4. Back in File Manager, right-click the .zip and choose Extract.
  5. If the files landed inside an extra folder (for example public_html/my-site/index.html), open that folder, select everything, and Move it up into public_html.
  6. Delete the .zip so it doesn't use up your storage.

Option 2: FTP (better for frequent updates)

  1. In cPanel, open FTP Accounts and create an account. Set its Directory to public_html so it can't touch anything else.
  2. Install an FTP app such as FileZilla.
  3. Connect using the settings under Configure FTP Client next to the account. Use FTP over TLS (FileZilla calls it “Require explicit FTP over TLS”) so your password isn't sent in the clear.
  4. Drag your site's files from the left-hand pane (your computer) to the right-hand pane (Dredge).

Check it

Visit your domain. If you still see an old page, your browser may have cached it; try a private window. If you see a list of files instead of your site, the index.html isn't directly inside the folder.

File and folder names are case-sensitive on Dredge. A link to Photo.JPG won't find photo.jpg, even if it worked on your computer.
