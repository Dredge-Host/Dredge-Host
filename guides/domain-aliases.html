Point multiple domains to one site

Own more than one domain name? You can make them all show the same website, or redirect the extras to your main domain.

Option 1: Domain alias (same content, both URLs work)

  1. Point the extra domain's nameservers at Dredge, just like you did for your main domain (see Connect a domain).
  2. In cPanel, open Domains and click Create A New Domain.
  3. Type the extra domain name.
  4. Make sure Share document root is ticked and the path points to public_html (your main site's folder).
  5. Click Submit.

Both domains now serve the same files. AutoSSL will issue a certificate for the new domain on its next run.

Option 2: Redirect the extras (better for SEO)

If you'd rather have one canonical URL and redirect the others, set up the alias as above, then add a redirect using the Redirect a domain guide. A 301 redirect tells search engines that the main domain is the real one.

Email on alias domains

An alias domain can receive email too. Create mailboxes or forwarders for it in cPanel the same way you would for your main domain.

Remove an alias

In Domains, click Manage next to the alias domain and then Remove Domain. This doesn't delete any files since the alias shared the same folder.
